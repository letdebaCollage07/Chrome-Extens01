# 🖇️This is a Leadtracker

- Are u forgot leads, No worries it take care of you❤️.

## 🚀Features

- It takes the input(urls) from the user and save in localStorage, and every time user came back to extension it stay here till u delete it manualy

- It also save the tab automatic in one click so no worries. it is fast.

## 📘User Manual

- One Click on Save Input To save The Input Box item.
- One Click on SAve Tab to save The Tab link directly.
- Double Click in Delete all to  Delete all the Leads.
